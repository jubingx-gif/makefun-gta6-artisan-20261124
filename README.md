## 🚀 Overview
This is a high-performance open-world crime game prototype built with **Three.js** and **Cannon.js**. It is designed to run completely offline in a desktop browser, meeting the strict requirements of the make.fun $1,666 bounty.

## 🛠️ Features
- **3D City Engine**: Procedurally generated skyscrapers and dynamic sky system.
- **Physics Integration**: Real-time collision detection and gravity using Cannon.js.
- **FPS Controller**: Fluid first-person movement and interaction.
- **GTA Spirit**: Mission trigger points and crime-inspired visual aesthetics.
- **Artisan Aesthetic**: Neo-Brutalism v3 UI design with intentional asymmetric offsets (De-AI).

## 📦 How to Run
1. Clone this repository.
2. Open `index.html` in any modern desktop browser (Chrome/Edge recommended).
3. Use `WASD` to move and `Mouse` to look around.
